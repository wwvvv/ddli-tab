# 组件与界面实施检查

仅用于 DTab。数值与视觉规则以 [设计系统](../../../../docs/dtab-os-v1/06-DESIGN-SYSTEM.md) 为准；安全与数据合同以 [架构](../../../../docs/dtab-os-v1/02-ARCHITECTURE.md) 为准。

## Home 与 Dock

使用 Entity + Placement，不在每个格子复制完整业务对象。点击、菜单移动与拖拽调用同一命令；写入失败不能继续显示“已保存”。

最小组件边界可包含 HomeScreen、DesktopPage、DesktopItem、IconView、ItemLabel、FolderPanel、WidgetHost、Dock、EditToolbar；先查已存在实现再命名，不为了清单重复造组件。

页面与 Dock 的设置来自预设/个人数据。只改布局不改应用身份；自定义图标不覆盖系统权限提示。一个快捷方式在两处显示时，共享定义并保持独立放置。

检查：长中文标签、图片加载失败、空桌面、多个页面、文件夹弹出、拖动取消、目标无效、窄屏 Dock 超宽。没有鼠标时仍能打开菜单；没有触摸时仍能编辑。

## 图标、文件夹、组件

IconView 接收 IconRef，不接受任意 HTML。官网 favicon 失败提供降级；用户图标来自受控资产。上传/裁剪失败保留原选择，不用随机图假装上传成功。

FolderPanel 包含名称、子快捷方式、关闭/编辑动作。关闭后恢复焦点；删除空文件夹与解散非空文件夹的行为要明确，不能连带删除网址定义。文件夹套文件夹 V1 不支持。

WidgetHost 统一处理尺寸、加载/离线/错误/不可用和设置菜单；组件配置应校验，网络数据不能由截图 fixture 混进生产。未知旧组件保留配置与迁移提示。

## 添加 Sheet

一级只放网址、组件、文件夹；更多内容去商店。网址表单显示地址、名称、图标来源和目标位置；没有抓到标题时显示域名且可修改，不持续 spinner。

图标选择包含自动候选、上传、我的图标；游客本地资产与账号云资产显示真实状态。组件选择器显示已可用尺寸和预览，不要求重新购买已拥有内容。

提交状态与后端/本地事务一致。错误就地提示；保存中防重复；取消不清空其他桌面内容。宽屏对话框和窄屏 Sheet 共用一份表单，不各写一套验证。

## 商店

复用 CatalogCard、ProductDetail、PrimaryAction 等模式，但 Product 与 WebResource 仍是不同业务对象。分类数量来自真实已发布内容。

动作映射：系统应用打开；可选官方应用获取/打开；组件添加；主题预览/应用；网址添加到桌面。下架、客户端版本不符、未授权或网络失败时明确说明。

截图和封面为官方资源；名称/价格/有效期不能写死进展示组件。没有真实评分数据就不展示星级。商业收款未开放时不要保留可误触的购买按钮。

## 相册

先做空状态、真实分页、上传状态列表和查看器，再打磨动效。大列表不同时挂载所有原图，缩略图失败有占位与重试。

区分“从相簿移除”和“删除照片”。选择模式有明确数量/取消；查看器支持键盘上一张/下一张、Esc、关闭后返回原位置。焦点目标被虚拟化卸载时恢复到合理的列表锚点。

开发 fixture 用非敏感图片且只在明确 demo/test 环境中使用。云相册被安全 gate 禁止开放时，UI 不抹去提示，不调用公开图床链接替代私有链路。

## 设置与管理员预设编辑

用户设置为分组列表/详情，账号在顶部；根据真实状态显示登录、离线、冲突、额度和恢复提示。

恢复官方预设必须先备份并说明影响，不删除相册/权益。管理员预设编辑复用桌面展示与命令，但使用独立数据范围、持久横幅和发布确认。

Admin 管理列表维持高密度可读，不做大图标桌面；保留审计、分页和权限拒绝状态。UI 的“只有管理员看到”不替代 API 授权。

## 提交前

确认没有新增平行 token 系统、任意远程脚本入口、Apple 私有资产、重复状态真源或未请求模块。共享 token/布局/焦点机制的改动交给 CORE，不在页面分支静默重构。
