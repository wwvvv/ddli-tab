## 本轮范围

按 05-CODEX-TASKS 的 M2 范围，先实现独立于云服务、存储和界面的网格纯函数。在新分支提交，不合并 main、不创建云项目、不使用凭据、不运行远程 SQL。M1 的真实平台 gates 仍未通过，但不阻塞这部分本地开发。

- 新增 `apps/web/src/desktop/grid.ts`：网格验证、确定性空位查找、添加/移动/移除放置记录、按输入顺序 first-fit 排布预览。
- 1x1 快捷方式与 2x2、4x2、4x4 组件占格；验证整型尺寸/坐标、越界、重复 placement ID 和任意面积重叠。
- API 只处理 placementId；不操作 Entity、安装、会员或权限。删除一处放置不意味着删除内容定义或其他放置。
- 所有返回布局与原输入分离。移动失败不修改原布局；空间不足不截断列表、不缩小组件、不隐式新增页。
- 排布预览是确定性 first-fit，不是最优装箱求解器；碎片化也可能返回 GRID_FULL。上层应保留原布局并提供换页/手工调整。
- 单页上限 24 列、128 行是防御性计算边界，不是产品容量/云配额。不同断点使用不同 GridSize，调用不会自动回写任何断点记录。
